PHASE 2 TESTING GUIDE
=====================

Purpose
-------
This guide tests the complete Phase 2 workflow:

1. Detect and freeze the tray plane and centroid.
2. Confirm before data collection starts.
3. Track the human cleaning-device marker through human.py.
4. Reject unreliable marker poses and filter accepted poses.
5. Save marker and cleaning-head XYZ positions in the tray coordinate frame.
6. Plot, replay, and export the recorded path.


1. TEST SETUP
-------------

Hardware:

- Connect and power on the ZED camera.
- Fix the tray so that it cannot move after it is detected.
- Make sure the entire tray is visible to the camera.
- Make sure the ChArUco marker is firmly attached to the cleaning device.
- Keep the marker visible while moving the cleaning device.

Software:

- Activate the project environment.
- Run the commands from the Integration directory.

Example:

    cd ~/Documents/Surgical_Cleaning_Robot/Integration
    conda activate cleaning_robot


2. QUICK SOFTWARE CHECK
-----------------------

Check that phase2.py has no Python syntax errors:

    python -m py_compile phase2.py

Display the available commands:

    python phase2.py --help

Display help for recording:

    python phase2.py record --help

Display help for replaying:

    python phase2.py replay --help


3. OPTIONAL HUMAN-MARKER TEST
-----------------------------

Before running Phase 2, verify that human.py can see the cleaning-device
marker and calculate the cleaning-head pose:

    python human.py marker-test

Move the cleaning device slowly while keeping the complete marker visible.
The cleaning-head axes should follow the tool. Press Q or Escape to stop.

If this test fails, Phase 2 cleaning-head tracking will also fail. Check the
marker visibility, lighting, camera calibration, and the saved transform at:

    data/human/marker_to_cleaning_head.json


4. RECORD A TEST TRAJECTORY
---------------------------

Start Phase 2:

    python phase2.py record

The program selects the next available sequential filename automatically,
such as recording_007.json.

Confirmation 1 - freeze the tray:

- Wait until the tray mask is correctly aligned with the physical tray.
- Confirm that the displayed centroid is near the tray center.
- Confirm that the plane grid follows the tray surface.
- Press SPACE only when the result is correct.
- Press Q or Escape to cancel instead.

After SPACE is pressed, tray object detection and plane fitting are turned off.
Do not move the tray or camera after this point.

Confirmation 2 - start data collection:

- Inspect the frozen tray overlay one more time.
- Place the cleaning device at the desired starting position.
- Make sure its entire ChArUco marker is visible.
- Press SPACE to start collecting data.
- Press Q or Escape to cancel.

During collection:

- Move the cleaning device slowly over the tray.
- Keep the marker visible and avoid sudden jumps.
- Green text means a cleaning-head pose was accepted.
- Red "Pose rejected" text means that frame is not saved.
- The rejection reason is displayed after the red text.
- Press Q or Escape when the test motion is complete.

Expected result:

    [INFO] Saved <number> tracked samples to .../recording_###.json


5. CHECK THE SAVED DATA
-----------------------

List the recordings:

    ls -lh data/phase2/recording_*.json

Inspect the most recent recording:

    tail -n +1 data/phase2/recording_007.json | less

Replace 007 with the number printed by the record command.

A current-format recording contains only the frozen tray information and the
data needed to plot or replay the cleaning-head path:

    {
      "tray_plane_camera": [a, b, c, d],
      "tray_centroid_camera_m": [x, y, z],
      "samples": [
        {
          "time_s": 0.0,
          "marker_xyz_m": [x, y, z],
          "cleaning_head_xyz_m": [x, y, z]
        }
      ]
    }

Interpretation of marker_xyz_m and cleaning_head_xyz_m:

- X and Y are positions along the tray surface.
- The tray centroid is X=0, Y=0, Z=0.
- The tray surface is Z=0.
- Positive Z points away from the tray and toward the camera.
- All saved positions are in metres.

The timestamps should increase from one saved sample to the next. Frames
rejected by human.py are intentionally absent.


6. PLOT THE RECORDING
---------------------

Plot a recording by number:

    python phase2.py plot 7

This loads:

    data/phase2/recording_007.json

Plot the latest recording without specifying a number:

    python phase2.py plot

Expected plot:

- 3D marker and cleaning-head paths in tray coordinates.
- A flat tray plane at Z=0.
- The tray centroid at the origin.
- Marker and cleaning-head X, Y, and Z position versus time.
- Distance from the tray centroid versus time.


7. REPLAY THE RECORDING
-----------------------

Replay by recording number:

    python phase2.py replay 7

Replay the latest recording:

    python phase2.py replay

Replay at half speed:

    python phase2.py replay 7 --speed 0.5

Replay at twice the speed:

    python phase2.py replay 7 --speed 2


8. SAVE THE REPLAY AS A VIDEO
-----------------------------

Verify that FFmpeg is available:

    ffmpeg -version

Save recording 7 as an MP4:

    python phase2.py replay 7 --save

Expected output file:

    data/phase2/replay_007.mp4

Save a half-speed video:

    python phase2.py replay 7 --speed 0.5 --save

Warning: saving the same recording again uses the same replay filename and
overwrites that replay video. It does not modify the JSON recording.


9. REPEATABILITY TEST
---------------------

For a basic repeatability experiment:

1. Keep the camera and tray fixed for every trial.
2. Choose clear start and end locations on the tray.
3. Record the same motion at least three times.
4. Use approximately the same speed for every trial.
5. Plot each recording and compare its X, Y, and Z path.
6. Check whether the repeated paths have similar positions, shapes, and tray
   heights before attempting robot replay.

Example:

    python phase2.py record
    python phase2.py record
    python phase2.py record

Then plot each new recording by its printed number.


10. COMMON MESSAGES
-------------------

Searching for tray plane...
    No complete tray plane is currently available. Improve tray visibility,
    depth quality, or lighting and keep the camera still.

Pose rejected: insufficient_markers
    The quality gate cannot see enough marker squares. Show the full marker.

Pose rejected: insufficient_charuco_corners
    Too few ChArUco corners were detected. Improve focus, distance, or lighting.

Pose rejected: mean_reprojection_error
Pose rejected: corner_reprojection_error
    The detected marker geometry does not fit the camera model accurately.

Pose rejected: translation_jump
Pose rejected: rotation_jump
Pose rejected: linear_speed
Pose rejected: angular_speed
    The measured pose changed too far or too quickly to be trusted. Move more
    slowly and keep the marker continuously visible.

Pose rejected: reacquiring_1_of_2
    Tracking was lost and human.py is waiting for another consistent pose
    before accepting data again.

Recording contains no tracked samples
    No marker observations passed the human.py quality checks. Repeat the
    marker-test and ensure the complete marker remains visible.

Recording not found
    The requested number does not exist. List available files with:

        ls data/phase2/recording_*.json


11. PASS CRITERIA
-----------------

The current Phase 2 test passes when:

- The tray is detected and frozen only after the first SPACE confirmation.
- Object and plane detection stop after the tray is frozen.
- Data collection starts only after the second SPACE confirmation.
- Accepted marker and cleaning-head positions follow the physical device.
- Rejected marker observations are not added to the trajectory.
- The JSON file contains increasing timestamps and plausible tray XYZ values.
- The plot and live replay load successfully.
- The saved MP4 plays successfully when --save is used.
